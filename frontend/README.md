# Cafe KiriKopi - Frontend

This is the customer-facing React application for Cafe KiriKopi.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

## Technologies

- React 19
- Vite
- React Router DOM
- Axios

For more details on the full project, please see the [main README](../README.md) in the project root.
